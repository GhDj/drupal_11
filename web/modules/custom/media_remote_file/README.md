## INTRODUCTION

The Media Remote File module is an integration tool that allows you to use file
urls as media sources for audio and video.

The primary use case for this module is:

- Create media entities with audio files hosted remotely
- Create media entities with video files hosted remotely
- Display these using `<audio>` or `<video>` HTML tags.

## REQUIREMENTS

Requires the core media and link modules.

## INSTALLATION

Install as you would normally install a contributed Drupal module.
See: https://www.drupal.org/node/895232 for further information.

## CONFIGURATION
- Add a Link field to your media entity type
- (optional) Select "Remote file" as the source type
- Select the display formatter "Remote video" or "Remote audio"
