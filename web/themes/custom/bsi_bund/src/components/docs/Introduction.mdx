# Storybook Component Library

Welcome to the component library! This is a comprehensive Storybook-based design
system built with TypeScript, SCSS, and Vite.

## About This Library

This component library follows industry best practices:

- **Atomic Design Methodology**: Components are organized from simple to complex
- **Type-Safe Templates**: TypeScript-based template functions for robust
  development
- **YAML Data Integration**: Separate data from presentation for better
  maintainability
- **Accessibility First**: Built-in accessibility testing and ARIA support
- **Modern Tooling**: Vite for fast builds, Vitest for testing, ESLint for code
  quality

## Component Organization

Components are structured following Atomic Design principles:

- **Base**: Foundation elements (colors, icons, spacing, ...)
- **Atoms**: Basic building blocks (button, heading, icon, ...)
- **Molecules**: Simple component groups (link, form fields, ...)
- **Organisms**: Complex UI components (header, card, form, ...)
- **Pages**: Full page compositions

## Explore the Library

Navigate through the sidebar to explore all available components, organized by
complexity level. Each component includes:

- Live interactive examples
- Component documentation
- Usage code snippets
- Accessibility testing results
